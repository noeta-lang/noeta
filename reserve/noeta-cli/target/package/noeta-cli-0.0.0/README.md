# noeta-cli

Command-line interface for the **Noeta** programming language (source
extension `.noe`).

> ⚠️ **This is a name-reservation placeholder (`0.0.0`).**
> The language is under active development and this crate does nothing useful
> yet. It is published only to hold the `noeta-cli` name (and the `noeta`
> command) until the first tagged release.

Installing it (`cargo install noeta-cli`) currently produces a `noeta` binary
that prints a "not released yet" notice.

Follow development at <https://noeta.dev>.
