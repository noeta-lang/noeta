# Noeta

**Noeta** is a programming language (source extension `.noe`).

> ⚠️ **This is a name-reservation placeholder (`0.0.0`).**
> The language is under active development and this crate exposes no
> functionality yet. It is published only to hold the `noeta` name until the
> first tagged release.

At its first real release, this crate will become the **embeddable library
entry point** — a stable API for hosting Noeta as a scripting language inside
other Rust programs (game engines, tools, plugins), in the spirit of `rlua`,
`rhai`, and `deno_core`.

Follow development at <https://noeta.dev>.
