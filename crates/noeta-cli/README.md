# lang-cli

The `lang` toolchain binary.

- **Takes in:** CLI args
- **Emits:** the `lang` binary with `run`, `repl`, and `test` subcommands. Thin glue over the pipeline crates.

Part of the `lang` compilation pipeline (see the repository `ARCHITECTURE.md` and `AGENTS.md` for the crate map and where each kind of change goes).
