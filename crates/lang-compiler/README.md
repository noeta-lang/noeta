# lang-compiler

The bytecode compiler: AST → `Module`.

- **Takes in:** an AST `Program` (from `lang-ast`); `PRELUDE_NAMES` (from `lang-builtins`). Internally it lowers to the **Core IR** (`lang-ir`) and runs the precise-RC passes (`lang-ir-passes`: liveness → drop insertion → reuse) before emitting bytecode, so the VM executes the *same* RC-annotated program the reference backend does.
- **Emits:** a `lang-bytecode` `Module` (the prototype table), or `Unsupported` for any construct outside the VM's subset (essentially never for real programs — the VM covers the whole language).

It lowers essentially the whole language: literals and bindings, arithmetic/comparison/logic and `~` concatenation, functions and **closures** (arrow and block, the `|>` pipeline), collections and their builtins/methods, string interpolation, the **object model** (structs/classes/enums on shapes, all-fields/`..spread`/defaulted literals, member access, associated functions and instance methods), tuples, generics, trait/operator dispatch, `match`/`?`/`??`, unions and `is`/`.as<T>()` narrowing, generators and `async`/`await`, isolates and channels, and packed value types. Names resolve through a two-level model: frame-local registers for parameters/locals (a method's register 0 is the receiver, its field names resolving against it) and a by-name global table for top-level bindings and function names; a nested closure captures its free variables as **upvalue cells** (`MakeClosure` with `CaptureFrom::Local`/`Upvalue`, closure conversion in `freevars.rs`). Register allocation is a reuse-aware graph-coloring post-pass (`regalloc.rs`). A three-pass compile registers every top-level `struct`/`class`/`enum`/`use` first (so forward references and shapes exist), then compiles class methods, then the top-level program. The lowering mirrors the reference backend's evaluation order and exact diagnostic text/spans so the differential oracle sees identical `RunResult`s.

Part of the `lang` compilation pipeline (see the repository `ARCHITECTURE.md` and `AGENTS.md`).
